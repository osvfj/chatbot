# Diagnóstico diferencial mediante conversación

Una imagen no debe interpretarse aislada. El sistema compara tres fuentes: la predicción visual, lo que el usuario describe y una fotografía de seguimiento cuando existe discrepancia.

## Preguntas útiles

- ¿El síntoma está en la cara superior o en el envés?
- ¿Hay polvo anaranjado, punteado fino, telarañas o perforaciones?
- ¿El daño aparece en una hoja o en muchas?
- ¿Desde cuándo se observa y se está extendiendo?
- ¿La planta atraviesa sequía, exceso de humedad o sombra densa?

La respuesta “no observo ninguno de esos signos” es evidencia de ausencia para esas hipótesis, pero no prueba que toda la planta esté sana. La conclusión debe limitarse a la hoja o a las fotografías disponibles.

## Reglas de comunicación

- La confianza visual baja exige una fotografía mejor o revisión técnica.
- Una contradicción entre texto e imagen exige otra observación, no una acusación.
- Una conclusión final debe decir qué evidencia la respalda y cuál es su límite.
