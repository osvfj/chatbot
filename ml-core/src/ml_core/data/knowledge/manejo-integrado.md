# Manejo integrado del cafetal

El manejo integrado no significa aplicar un producto cada vez que aparece una mancha. Consiste en combinar prevención, monitoreo, prácticas culturales, conservación de enemigos naturales y control dirigido cuando la evidencia y el umbral de daño lo justifican.

## Principios prácticos

1. Inspeccionar el cafetal periódicamente y registrar qué hojas, ramas o frutos presentan cambios.
2. Tomar fotografías nítidas del síntoma y del envés de la hoja.
3. Regular sombra, ventilación y manejo del tejido según las condiciones locales.
4. Mantener nutrición y agua adecuadas; el estrés puede aumentar la vulnerabilidad de la planta.
5. Preferir variedades tolerantes o resistentes cuando sean apropiadas para la zona.
6. Consultar a un técnico antes de elegir productos y dosis.

Una recomendación aislada no debe tratarse como receta universal. La altitud, variedad, edad del cafetal, humedad, carga de frutos y manejo previo pueden cambiar la decisión.

## Cómo utiliza esto Cafebot

Cafebot recupera este documento cuando la consulta se relaciona con prevención o manejo integrado. El LLM recibe el fragmento Markdown como conocimiento de apoyo, pero debe conservar la política: no confirmar diagnósticos inciertos, no inventar dosis y recomendar revisión profesional cuando la evidencia sea insuficiente.
